# Чек-листы приёмки

Что проверяет человек после каждого шага. Проверка агентом приёмку не
заменяет: шаг закрывает только Александр.

Общее для всех шагов: открыть https://raikhin.duckdns.org/ — замок в адресной
строке без предупреждений, страница грузится с телефона и с компьютера.

---

## Ш1. Шаблон на прод как статика

- [ ] Приглашение открывается и выглядит как исходный макет: тёмно-синий фон
      с разметкой площадки, крупный номер 37 за именем, табло с обратным
      отсчётом, плитки Дата / Время / Площадка.
- [ ] **Заголовки набраны узким «спортивным» шрифтом, а не обычным
      системным.** Смотреть на «АЛЕКСАНДР РАИХИН», «ДРЕСС-КОД», «КАРТОЧКА
      ИГРОКА». До этого шага кириллица падала в системный шрифт — если
      разница не нравится, см. решение Р6, откатывается заменой двух
      CSS-переменных.
- [ ] Обратный отсчёт идёт: секунды меняются каждую секунду, числа совпадают
      с оставшимся временем до 22.08.2026 16:00.
- [ ] Ползунок «готовность угарать» двигается и меняет подпись под собой.
- [ ] В выпадающем списке напитков выбор «Свой вариант» открывает
      дополнительное поле.
- [ ] **Над формой видна жёлтая плашка «Запись пока закрыта»**, кнопка внизу
      серая и не нажимается. Это ожидаемо: сохранять ответы будет шаг 3.
- [ ] Страница не «мигает» подменой шрифта при загрузке и открывается при
      выключенном VPN (шрифты лежат на сервере, не тянутся из Google).
- [ ] Телефон: горизонтальной прокрутки нет, ничего не вылезает за экран.

## Ш2. Бэкенд-скелет

- [ ] `https://raikhin.duckdns.org/api/health` отдаёт `{"status":"ok"}`.
- [ ] Приглашение продолжает открываться как раньше.
- [ ] После перезагрузки сервера `/api/health` снова отвечает сам.

## Ш3. База и приём заявок

- [ ] Заполнить форму → подтверждение на экране → перезагрузить страницу →
      запись на месте.
- [ ] Отправить пустое имя → понятная ошибка, а не белый экран.
- [ ] Отправить форму дважды подряд → дубликат не создаётся.

## Ш4. Ростер и правка ответа

- [ ] Заявки с двух разных устройств обе видны в списке.
- [ ] По своей персональной ссылке меняется число гостей, в ростере
      обновляется, дубль не появляется.
- [ ] Решить окончательно: полное ФИО в публичном списке или только имя (Р4).
