# Чек-листы приёмки

Что проверяет человек после каждого шага. Проверка агентом приёмку не
заменяет: шаг закрывает только Александр.

Общее для всех шагов: открыть https://raikhin.duckdns.org/ — замок в адресной
строке без предупреждений, страница грузится с телефона и с компьютера.

Резервный адрес, если у кого-то из гостей основной не открывается:
http://91.212.150.225/ — работает без DNS вообще (открытый HTTP, годится
«чтобы хоть посмотреть»).

---

## Ш1. Шаблон на прод как статика

- [ ] Приглашение открывается и выглядит как исходный макет: тёмно-синий фон
      с разметкой площадки, крупный номер 37 за именем, табло с обратным
      отсчётом, плитки Дата / Время / Площадка.
- [ ] **Заголовки набраны узким «спортивным» шрифтом, а не обычным
      системным.** Смотреть на «АЛЕКСАНДР РАИХИН», «ДРЕСС-КОД», «КАРТОЧКА
      ИГРОКА». До этого шага кириллица падала в системный шрифт — если
      разница не нравится, см. решение Р6, откатывается заменой двух
      CSS-переменных.
- [ ] Обратный отсчёт идёт: секунды меняются каждую секунду, числа совпадают
      с оставшимся временем до 22.08.2026 16:00.
- [ ] Ползунок «готовность угарать» двигается и меняет подпись под собой.
- [ ] В выпадающем списке напитков выбор «Свой вариант» открывает
      дополнительное поле.
- [ ] **Над формой видна жёлтая плашка «Запись пока закрыта»**, кнопка внизу
      серая и не нажимается. Это ожидаемо: сохранять ответы будет шаг 3.
- [ ] Страница не «мигает» подменой шрифта при загрузке и открывается при
      выключенном VPN (шрифты лежат на сервере, не тянутся из Google).
- [ ] Телефон: горизонтальной прокрутки нет, ничего не вылезает за экран.

## Ш2. Бэкенд-скелет

- [ ] `https://raikhin.duckdns.org/api/health` отдаёт `{"status":"ok"}`.
- [ ] Приглашение продолжает открываться как раньше.
- [ ] После перезагрузки сервера `/api/health` снова отвечает сам.

## Ш3. База и приём заявок

- [ ] Заполнить форму → зелёное подтверждение «Вы в стартовом составе».
- [ ] Перезагрузить страницу → ваши ответы подставлены, сверху плашка
      «Вы уже в составе», кнопка называется «Сохранить изменения».
- [ ] Поменять количество гостей и сохранить → «Изменения сохранены»,
      второй записи не появляется.
- [ ] Нажать кнопку с пустым именем → красная понятная ошибка.
- [ ] Выбрать «Свой вариант» напитка, вписать текст, сохранить,
      перезагрузить → вариант на месте.
- [ ] Открыть сайт в режиме инкогнито → форма пустая, как у нового гостя.
- [ ] Личное сообщение и аллергии нигде публично не показываются.

## Ш4. Ростер и правка ответа

- [ ] Заявки с двух разных устройств обе видны в списке.
- [ ] По своей персональной ссылке меняется число гостей, в ростере
      обновляется, дубль не появляется.
- [ ] Решить окончательно: полное ФИО в публичном списке или только имя (Р4).

## Ш5. Админка

Перед проверкой в Settings → Secrets and variables → Actions должен быть
добавлен секрет `ADMIN_PASSWORD`, иначе `/admin` честно отвечает 503.

- [ ] `https://raikhin.duckdns.org/admin` спрашивает логин и пароль;
      логин `admin`, пароль — значение секрета.
- [ ] Неверный пароль не пускает.
- [ ] В таблице видны все заявки: полное имя, гостей, напиток, готовность,
      аллергии, личное сообщение.
- [ ] Колонка «В списке» показывает сокращённое имя — ровно то, что видно
      гостям на публичной странице.
- [ ] Кнопка «Имя» меняет имя, превью в колонке «В списке» обновляется.
- [ ] Кнопка «Удалить» спрашивает подтверждение и убирает запись;
      **этим убрать тестовую запись «Проверка Связи»**.
- [ ] «Скачать CSV» даёт файл, который открывается в Excel с русскими
      буквами и разложен по колонкам.
- [ ] Приглашение на `/` продолжает работать.

## Ш6. Калькулятор бара

- [ ] В форме под выбором напитка есть галочка «Принесу своё».
- [ ] Отметить её, сохранить, перезагрузить страницу → галочка на месте.
- [ ] В админке раздел «Закупка бара» показывает строки вида
      «Виски · 3 чел. · 0,9 л · 2 бутылки 0,7 л».
- [ ] Над таблицей написано, сколько человек вошло в расчёт и сколько
      принесут своё.
- [ ] Свой вариант напитка («Кальвадос») стоит отдельной строкой с пометкой
      «решить вручную», а не с придуманным объёмом.
- [ ] Ссылка «Из чего считается» раскрывает нормы на человека.
- [ ] Удалить заявку → цифры в закупке пересчитались сразу.
- [ ] Числа склоняются: «1 бутылка», а не «1 бутылок».

## Ш7. Telegram-бот

- [ ] В админке блок Telegram показывает имя вашего бота, а не ошибку.
- [ ] Открыть оттуда одноразовую ссылку, нажать в боте «Старт» → блок
      показывает «✓ ваш чат привязан».
- [ ] Кнопка «Тестовое сообщение» → сообщение приходит вам в Telegram.
- [ ] На странице приглашения после записи появляется кнопка
      «Подключить Telegram»; переход в бота и «Старт» → бот отвечает по имени.
- [ ] После этого на странице вместо кнопки — «✓ Telegram подключён».
- [ ] Записаться ещё раз с другого устройства → вам в Telegram приходит
      уведомление о новой заявке.
- [ ] Команда `/stop` в боте отключает напоминания.

## Ш8. Напоминание за два дня

- [ ] В админке раздел «Напоминание» показывает «Уйдёт 20 августа в 16:00
      (МСК)» и что окно пока закрыто.
- [ ] Видно поимённо, кто получит, и сколько гостей **без Telegram**.
- [ ] «Текст сообщения» раскрывается и читается нормально, без `\n`.
- [ ] Кнопка «Отправить сейчас принудительно» → сообщения встают в очередь.
- [ ] Запустить Actions → Telegram outbox → Run workflow → напоминание
      приходит в Telegram.
- [ ] Нажать «Отправить сейчас» второй раз → «В очереди: 0», дублей нет.
- [ ] Таймер на странице приглашения показывает верное время (проверить
      можно, сменив часовой пояс на телефоне).

## Ш9. Календарь и аллергии

- [ ] На странице под табло есть кнопка «Добавить в календарь».
- [ ] **С телефона:** нажать → событие добавляется в календарь.
- [ ] В событии верны дата и время (22 августа, 16:00) и стоит напоминание
      за два дня.
- [ ] В админке раздел «Ограничения в еде» перечисляет всех, кто их указал.

Ждут данных от вас: точный адрес площадки (для карты и поля «место» в
календаре) и программа вечера.

## Ш10. Бэкапы и устойчивость

- [ ] `curl https://raikhin.duckdns.org/api/health` → в поле `backup`
      есть `last_at` не старше суток и `count` от 1 до 7.
- [ ] Кнопка «Добавить в календарь» скачивает файл.
- [ ] Порядок восстановления описан в `docs/RUNBOOK.md` и понятен.
- [ ] По желанию: попросить агента погасить сервис — приглашение должно
      остаться читаемым, а форма показать «Запись временно недоступна».

## Ш11. Превью ссылки и закрытие служебных путей

- [ ] Отправить ссылку https://raikhin.duckdns.org/ самому себе в Telegram →
      появляется карточка с картинкой, заголовком и «22 августа, 16:00,
      CleverLOFT».
- [ ] На странице раздел «Где играем» с адресом и метро; кнопка «Построить
      маршрут» открывает Яндекс.Карты на нужном месте.
- [ ] Нигде не осталось «Лофт в Сити».
- [ ] `curl https://raikhin.duckdns.org/api/health` отдаёт только
      `status`, `version`, `uptime_seconds`.
- [ ] `/tls-status` и `/tg-status` отвечают 404.
- [ ] В админке первая строка показывает версию и возраст бэкапа.

**Уточнить у площадки:** номер строения (стр. 2 или стр. 3) — на их сайте
встречаются оба, а гостям нужна конкретная дверь.

## Ш12а. Плейлист

- [ ] В форме есть поле «Трек на разминку».
- [ ] Заполнить и сохранить → трек появляется в разделе «Плейлист» ниже,
      с вашим сокращённым именем.
- [ ] Перезагрузить → поле подставлено, можно поменять.
- [ ] В админке раздел «Плейлист» показывает полные имена и кнопку
      «Скопировать список».

## Ш12б. Фотоальбом

- [ ] До записи в разделе «Фотоальбом» написано, что сначала нужно записаться,
      формы загрузки нет — но чужие фото уже видны.
- [ ] После записи появляется форма: выбрать файл, подпись, «Добавить фото».
- [ ] **С телефона:** загрузить фото из галереи → появляется в альбоме,
      повёрнутое правильно, а не набок.
- [ ] Нажать на превью → открывается фото целиком.
- [ ] Попробовать загрузить шестое фото → «Больше 5 фото не принимаем».
- [ ] В админке раздел «Фотоальбом»: сетка превью, объём на диске, удаление.
- [ ] Удалить гостя в админке → его фото исчезают из альбома.

Стоит знать: EXIF срезается, поэтому геометки съёмки в открытый альбом
не попадают. HEIC с iPhone напрямую не принимается — сообщение об ошибке
просит сохранить как JPEG.
