## Р1. Регистрация гостей — через Telegram
**Дата:** 2026-07-29 · **Решил:** Александр

Вход и опознание гостя — через Telegram, без паролей и почты. Один вход даёт
сразу и личность, и канал для напоминаний, поэтому отдельный сбор контактов
не нужен.

## Р2. Канал напоминаний — Telegram
**Дата:** 2026-07-29 · **Решил:** Александр

Напоминание за 2 дня уходит в Telegram. Email не используем: домен
`duckdns.org` без SPF/DKIM/DMARC почти гарантированно попадёт в спам, а
настройка почтовой репутации к 22 августа не окупается.

## Р3. Домен — raikhin.duckdns.org
**Дата:** 2026-07-29 · **Решил:** Александр (поддомен заведён вручную)

Боевой адрес — https://raikhin.duckdns.org/. Сертификат Let's Encrypt
выпускается Caddy автоматически.

Реализовано режимом `TLS_MODE: fixed` в `.github/workflows/deploy.yml`:
домен задан константой, секреты DuckDNS не требуются. Обновление A-записи
через API DuckDNS включится само, если в секреты добавить `DUCKDNS_TOKEN`
и `DUCKDNS_SUBDOMAIN` — до тех пор запись остаётся такой, как выставлена руками.

## Р4. Ростер публичный
**Дата:** 2026-07-29 · **Решил:** Александр

Список подтвердившихся видят все, у кого есть ссылка.

**Уточнено 2026-07-29:** в публичном ростере — имя и первая буква фамилии
(«Пётр С.»), полные данные видны только в админке. Полные ФИО гостей —
персональные данные, публиковать их по открытой ссылке не нужно.

Отсюда следует требование к API: `GET /api/roster` отдаёт уже сокращённую
форму, а не полное имя, которое фронтенд потом обрезает. Иначе полные ФИО
уедут в браузер любого, кто откроет devtools.

## Р5. Стек — Python + FastAPI + SQLite, фронтенд без сборки
**Дата:** 2026-07-29 · **Предложил:** агент, принято в составе плана

Бэкенд: FastAPI + SQLite за `reverse_proxy` в Caddy. Фронтенд остаётся
обычным HTML/CSS/JS без npm и сборщика — это сохраняет текущий пайплайн
деплоя (`rsync` статики) без изменений.

## Р6. Шрифты — локальные, кириллические Oswald и Russo One
**Дата:** 2026-07-29 · **Предложил:** агент, ожидает подтверждения

В исходном шаблоне заголовки набраны Anton, а акцентные надписи — Bangers.
**У обоих шрифтов нет кириллицы** (подтверждено по подмножествам Google
Fonts: только latin, latin-ext, vietnamese). То есть «Александр Раихин»,
«37 — ЮБИЛЕЙНЫЙ СЕЗОН!», все заголовки разделов и кнопка отображались
системным шрифтом, а не задуманным.

Замена: Anton → **Oswald 700**, Bangers → **Russo One** для кириллицы.
Bangers оставлен только для латинского «SMART HERO». Все файлы скачаны в
`site/fonts/` (подмножества cyrillic + latin), страница больше не зависит
от `fonts.googleapis.com`.
