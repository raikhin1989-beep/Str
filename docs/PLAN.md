## Правила работы

1. Один шаг — один коммит с деплоем, без попутных правок.
2. Каждый шаг заканчивается ссылкой и списком того, что должно быть видно.
3. Ломающие изменения — только с понятным откатом на предыдущий коммит.
4. Никаких заглушек, притворяющихся рабочими: неготовая функция честно
   говорит об этом на экране.
5. Секреты (токен бота, пароль админки) — только в GitHub Secrets.
6. Шаг не закрыт, пока не обновлены PLAN.md, CHANGELOG.md и VERIFY.md.
