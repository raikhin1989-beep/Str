# API

Всё под префиксом `/api/*` — Caddy отдаёт его в uvicorn, остальное статикой.
База: `https://raikhin.duckdns.org`. Swagger и `/openapi.json` отключены.

## GET /api/health

```
curl https://raikhin.duckdns.org/api/health
{"status":"ok","version":"<SHA коммита>","uptime_seconds":30.8}
```

`version` — SHA задеплоенного коммита. Отличает «сервис отвечает» от
«отвечает тот код, который мы только что выложили».

## POST /api/rsvp

Приём и правка заявки. Один и тот же эндпоинт создаёт и обновляет.

```
curl -X POST https://raikhin.duckdns.org/api/rsvp \
  -H 'Content-Type: application/json' \
  -d '{"name":"Пётр Смирнов","guests_count":2,"drink":"Виски","hype":9,
       "allergies":"без орехов","message":"до встречи"}'
{"ok":true,"token":"xT9Aw3...","updated":false}
```

| Поле | Тип | Ограничения |
| --- | --- | --- |
| `name` | строка | 2–80 символов, обязательно |
| `guests_count` | целое | 1–10, по умолчанию 1 |
| `drink` | строка | 1–40 символов, обязательно |
| `hype` | целое | 1–10, по умолчанию 7 |
| `allergies` | строка | до 200 символов |
| `message` | строка | до 500, в публичный список не попадает |
| `token` | строка | токен своей записи, если правим существующую |
| `website` | строка | ловушка для ботов, должна быть пустой |

`token` в ответе фронтенд кладёт в `localStorage` — это и есть «личный
ключ» гостя, паролей нет. `updated: true` означает, что запись обновлена,
а не создана.

**Защита от дублей** двухуровневая: сначала ищем запись по токену, затем —
по совпадению хэша IP и имени. Второе ловит двойной клик и повторный заход
из другого браузера на том же роутере.

**Ловушка для ботов:** если `website` не пуст, ответ выглядит успешным, но
ничего не сохраняется — чтобы бот не понял, что его отсеяли.

**Лимит:** 12 новых записей в час с одного IP → `429`. Обновления
существующей записи под лимит не попадают.

### Ошибки

| Код | Когда | Тело |
| --- | --- | --- |
| 400 | не прошла валидация | `{"error":"Проверьте поле «имя» — значение не подходит."}` |
| 429 | превышен лимит | `{"error":"Слишком много заявок с этого адреса..."}` |

Ошибки валидации сводятся к одной строке по-русски: страница показывает её
гостю как есть, без разбора структуры ошибок FastAPI.

## GET /api/rsvp?token=…

Своя запись целиком — это собственные данные гостя.

```
curl 'https://raikhin.duckdns.org/api/rsvp?token=xT9Aw3...'
{"token":"xT9Aw3...","name":"Пётр Смирнов","guests_count":2,"drink":"Виски",
 "hype":9,"allergies":"без орехов","message":"до встречи"}
```

`404` — записи нет (например, токен остался от сброшенной базы). Страница
в этом случае чистит `localStorage` и показывает пустую форму.

## Данные

SQLite в `/opt/str-api/data/str.db`, вне вебрута. Схема меняется только
добавлением записи в `MIGRATIONS` (`backend/db.py`) — применённые версии
отмечаются в `schema_migrations`, редактировать применённую миграцию
бесполезно, на сервере она не переиграется.

IP хранится только как соль+SHA-256 (`ip_hash`): он нужен для дедупликации
и лимитов, а само значение — лишние персональные данные.

Миграции применяются **при старте приложения**. Если база потеряна, схема
восстановится только после перезапуска `str-api`, а не при первом запросе.
